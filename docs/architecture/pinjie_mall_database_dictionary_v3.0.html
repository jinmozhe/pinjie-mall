三大核心查阅准则

1. 现在这个 SKU 卖多少钱？ 先查 product_skus 基础标价，再结合当前会员身份与购买数量，通过 member_price_rules 计算最终统一报价，严禁读取历史订单价格。

2. 这个历史订单当时是多少钱成交的？ 直接读取 order_items 中的 unit_price、line_amount 以及 orders 的 price_breakdown 不可变快照，严禁回查当前商品标价重新计算。

3. 用户当前有多少可提现佣金？ 权威读取佣金钱包的 wallet_accounts 可用余额（available_amount），并校验是否有欠款记录。commission_records.status 仅代表单笔分佣事实的冻结与解冻状态，不是钱包余额的物理存储。

4. 全库核心 JSONB 字段契约规范

系统针对动态配置、快照展开与多级分销矩阵，严格规定了 JSONB 字段的标准 Schema，禁止写入未受控属性：

  • product_skus.wholesale_prices（阶梯批发价）： 严格递增阶梯 [{"min_quantity": 10, "price": "80.00"}]，仅对单 SKU 生效。
  • member_price_rules.criteria（会员价适用条件）： 包含购买件数区间与生效时间窗口。
  • commission_distribution_rules.rules（三级分销矩阵）： 严格限定 1/2/3 层级，比例总和不得超过 1.000000。
  • orders.price_breakdown（订单结算快照）： 固化商品合计、实付运费、总优惠及最终实付金额。
  • system_settings.setting_value（运费配置）： 严格校验 default_rule 与 region_rules 行政区划防重。
