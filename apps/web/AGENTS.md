# Web 项目停用与冻结规则

## 1. 废弃与停用状态

- 本文件适用于 `apps/web/**`，并继承仓库根 `AGENTS.md`。
- 本项目定位为微信小程序全栈商城，应用层完全不需要 Web 端，C 端唯一交付形态为小程序端。
- `apps/web` 进入永久停用与代码冻结状态，不属于本项目交付目标，禁止在此投入开发和维护资源。

## 2. 禁止 WEB 端口与开发服务

- 完全禁止启动 Web 开发服务，完全禁止在本地开发、测试或容器编排中监听或暴露 3000 及任何 WEB 端口。
- 本地开发服务仅运行 Backend（8000 端口）与 Admin（3001 端口），日常启动命令完全禁止拉起 Web 端。
- 禁止修改、扩展或在此目录新增任何业务逻辑与页面。

## 3. 门禁与构建隔离

- 本目录仅作为 Monorepo 历史骨架保留，仅服从仓库自动化门禁的基础类型与语法检查，不代表具备业务功能。
- 禁止运行 Web 端生产构建、Vitest 单元测试、Playwright 浏览器测试及 E2E 验证。
- 阶段推进严格遵守项目原则：前阶段全面聚焦后端与管理端，小程序端作为后续独立阶段开发，Web 端完全废弃。
